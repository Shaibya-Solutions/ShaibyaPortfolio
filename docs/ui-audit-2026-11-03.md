# Service presentation and responsive audit — 3 November 2026

## Changes

- Software Solutions: replaced the rotating 3D cube/carousel with an accessible project selector and flat screenshot gallery. It reuses existing project data for billing automation, gym management, property CRM and website work. Screenshots transition with a short fade/slide; each project has its own description, capabilities and relevant portfolio destination. Arrow keys, Home and End select projects; motion reduction disables the transition.
- Digital Marketing: fixed the spring/keyframe exception. Position changes use springs, while the three-keyframe scale pulse explicitly uses a tween. The animation now has 48 deterministic nodes rather than 130 random nodes, pauses off-screen and respects reduced motion. A button supports touch and keyboard interaction alongside hover.
- Process cards: retain the four audit/design/production/optimisation steps, but no longer depend on an opacity-zero viewport entrance to become visible. The runtime crash previously interrupted the page; content now starts visible as well.
- Omnichannel preview: replaced the fixed-aspect, clipped browser mockup with a responsive image-and-content panel. All four selectors remain available, with manual control rather than automatic cycling. Local images replace the missing asset. Removed illustrative engagement numbers, ratings and cost-per-lead claims from mockups.
- Homepage social gallery: uses local, compressed WebP creative imagery, links to `@deepoffduty`, and offers pause/resume. Keyboard focus pauses the gallery and reduced-motion users get a static presentation. Duplicate marquee copies are excluded from keyboard navigation and accessibility announcements.
- Retail: replaced two references to a nonexistent screenshot with a relevant local showroom concept. Both placements explicitly identify it as illustrative rather than a client photograph.
- Kept the site's existing Proxima Nova typography and service-page colour palette. Updated sitemap content dates for the four pages whose content changed.
- Corrected the homepage's “See our work” anchor and supplied its target in the mobile layout as well. Added a production-export regression check for internal routes and section links across all 21 pages.
