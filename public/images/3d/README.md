# 3D service visuals

These visuals were generated for the 3D service page on 2026-11-02 and converted
into local WebP assets. They are illustrative concepts, not client screenshots
or evidence of commissioned work. The page labels them accordingly.

- `living-room-render.webp`: photorealistic architectural interior concept.
- `living-room-wireframe.webp`: an edit of that same room, preserving the camera
  and composition for the comparison slider.
- `architectural-residence.webp`: residential exterior visualization concept.
- `headphone-product.webp`: unbranded product visualization concept.
- `explorer-character.webp`: original stylized robot character concept.

Keep the paired room images at the same dimensions and framing. The comparison
uses full-size overlapping layers and clipping so dragging never rescales them.
